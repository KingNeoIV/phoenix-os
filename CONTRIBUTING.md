# Contributing

PhoenixOS and Shia16 are learning projects. I'm building an operating system and a programming language from scratch, and I'd like to meet other people who are still in college or teaching themselves and want to learn the same things. If that's you, you're welcome here, and you don't need to be an expert.

## The one rule: document what you do

I care more about understanding than speed. If you add or change something, explain it:

- Write comments that say why, not just what.
- Add a short note in `docs/` for anything new.
- For anything hard, write down what you think it does and what you don't understand yet. That's how I write my own notes in `docs/vision.md`.

If you have more experience than me, this matters even more. I'm trying to learn how it works, so showing your reasoning helps me and everyone else reading later.

## Setup

Right now the setup guide is for Windows: [docs/setup-windows.md](docs/setup-windows.md). It lists every tool, how to install it, and how to check that it works.

## Commit messages

I use this format:

```text
type(scope): description
```

Some examples from this repo:

```text
feat(docs): add vision, ladder, and borrowed tools
fix(repo): separated ignore rules onto their own lines
chore(repo): ignore build output
```

I keep to one file per commit when I can.

## How to take part

- **Start with an issue.** If you have an idea, a question, or something you want to work on, open an issue first so we can talk about it before you write code.
- **Tell me what you want to learn.** It helps me point you at the right milestone.
- **Small is fine.** A fixed typo or a clearer explanation counts.

I'm a full-time student, so I review when I can. It might take me a while to reply.

## How I work

I pull at the start of a session and push at the end. I make a commit for each file as I go, and I push them all together when I'm done.

## Questions and ideas

Open an issue on this repo. That's the best place to reach me for now.
