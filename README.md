# Project: PhoenixOS and Shia16

A tiny learning/hobby OS and programming language built from the groud up, name after my kids.

## Why this exits

This project is for learning perposes and is great for a portfolio project. I've named the OS and programming languages after my sons Phoenix and Shia. This project is necessary to under how hardware and software connects and is used towards understanding making systems for custom engineered CPU's, PCB's, and other devices such as robots. 

## What's inside

### PhoenixOS
PhoenixOS is going to be the baby in the womb figurativly speaking. The very first step is getting to understand the very fundimantals of the operating systems and will later grow into a full fledge operating system that be for mainly used on robotic or computor hardware.

### Shia16
Shia16 is going to be the programming language that will help create software for the OS. All this is gearing towards learning how to create a system for robotics.
